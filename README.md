# 🗂 Personal Dashboard

A clean, client-side personal dashboard built with **HTML**, **CSS**, and **Vanilla JavaScript**.  
No frameworks. No backend. All data lives in **localStorage**.

---

## Features

### MVP
| Feature | Description |
|---|---|
| ⏰ Greeting | Shows current date & time, greeting phrase based on time of day |
| ⏱ Focus Timer | 25-minute countdown with Start / Stop / Reset |
| ✅ To-Do List | Add, edit, mark done, delete — persisted in localStorage |
| 🔗 Quick Links | Save favourite websites as clickable chips |

## How to Run

1. Clone or download this repository.
2. Open `index.html` in any modern browser — no build step required.

## Deploy to GitHub Pages

1. Push to a GitHub repository.
2. Go to **Settings → Pages → Source: main / root**.
3. Your site will be live at `https://<username>.github.io/<repo>/`.
